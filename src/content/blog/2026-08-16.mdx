## The submain backlog

The most consequential thing about the current state is the submain branch. It is 27 commits ahead of main, unchanged since August 2. That is two weeks of finished work sitting unmerged.

- Enforcement-layer fixes covering const immutability, field/variant/loop-counter facts
- A rejection-shape harness

- Paired documentation commits for each feature
- README accuracy passes

Submain's own test matrix is at 414/414. There are no visible conflicts with main. The merge is additive. This has been the obvious first move for two weeks running, and it remains the clear first move whenever work resumes.

The PR backlog has grown to 83 open pull requests spanning from #287 (May 28) through #375 (August 15). All but one are automated daily log PRs. The exception is #347, a README version update. None have been merged.
