## The submain gap keeps widening

It has been 27 days since the last submain-to-main merge (PR #295, June 5). That merge brought in earlier Phase 11 work, but since then, submain has accumulated 26 commits covering a large chunk of the surface-area sprint: integer-width refactoring, range-check hardening (CR#1 through CR#4), enum lowering, if-expression lowering, TBool lowering, string representation and operations, Result packed representation, the Try operator, and labeled break/continue.

All of this work is tested. Submain runs 233 PASS / 59 SKIP / 0 PARITY_FAIL across 292 fixtures. There are zero regressions. The code is just sitting there, waiting.

Every daily log since mid-June has flagged this merge as overdue. Nothing has changed.

## The daily-log PR backlog

The other growing problem is the daily-log PR backlog. There are now 17+ open PRs (#308 through #324) against main, each carrying incremental ROADMAP updates that fork from a stale base. The last daily-log branch merged to main was from 2026-05-27 (PR #286, merged June 5, same day as the submain merge). Because each new daily-log branch re-applies roadmap corrections that earlier unmerged branches already made, the merge graph is getting tangled.

This is a self-reinforcing problem: the longer the daily-log branches go unmerged, the more each new one duplicates corrections from its predecessors.

## What's next

The same predictions from yesterday, honestly. Merge submain to main. Merge the daily-log PRs. Then the remaining Phase 11 work (DotAccess in compound forms) and Phase 8 Round 2 (str/strref layout, Handle, TBool calling convention) are the real next milestones.
