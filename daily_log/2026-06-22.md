## Decisions and direction

The D2.3a commit marks a deliberate start to the string arc, and the commit message is explicit about the strategy: begin with `len()` because it is the only string operation that can be lowered without introducing a string representation in the IR. Everything else in the string arc — concatenation, string comparison, interpolation — will require actual string IR types and host callbacks, which are not yet built.

The `len()` folding also closes the array-len gap (arrays had bounds checks and layout reads but len was unlowered), meaning this commit tightens two subsystems at once.

The approach is conservative: dynamic strings (whose length is not known at compile time) fall through to the SKIP path rather than attempting runtime-dispatched host callbacks. This is consistent with the project's pattern of lowering what can be lowered cleanly and deferring what needs new infrastructure.
