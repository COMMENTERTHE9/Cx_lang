- **CONFIRMED** — `3d7a2cd`: **JIT lowering of the `exit()` builtin** (known-issues #11). A `cx_exit(code: i32) -> !` host callback was added to `host_boundary.rs`, mirroring `cx_trap`'s shape. The lowering intercept in `lower.rs` handles `BuiltinKind::Exit` like the other statement-level builtins. `exit()` with no argument lowers as `exit(0)`. stdout is flushed before `process::exit` on the host side to match the interpreter's behavior — without it, `print(...); exit(N)` would agree on exit code but silently lose piped output. Exit-code fidelity verified at 0, 1, 3, 42, 125, 126, 127, 200, 255, and across the wrap boundary (256 -> 0, 300 -> 44). Seven fixtures converted from SKIP to PASS. Five files changed, 127 insertions.

- **CONFIRMED** — `1f4945c`: **Parser fix: `exit` added to the statement-level builtin guard.** Surfaced during exit verification — `t_exit_in_function` was still failing because the parser's `is_statement_level_builtin_call` listed `print`/`println`/`printn`/`assert`/`assert_eq` but not `exit`. A function body ending in `exit(...)` promoted the call into `ret_expr`, routing it through `lower_expr` (no builtin interception) instead of `lower_stmt`. The fix adds `exit` to the guard and documents the membership rule: a builtin belongs in the guard if and only if its registry `BuiltinRet` is `Void`. A new unit test enforces this rule against the registry, catching future omissions at `cargo test` time. 56 insertions, 6 deletions.

- **CONFIRMED** — `6c37339`: **JIT lowering of top-level `const` declarations** (known-issues #12). The `ConstDecl` lowering arm mirrors `TypedAssign`'s general path — lower the RHS, bind the SSA value to the const's binding. A width `Cast` handles the type mismatch that the semantic ConstDecl arm, unlike TypedAssign, does not resolve via `insert_cast_if_needed` (e.g., `const A: t32 = 5` arrives with I64 literal against I32 target). Assignment to a const is caught by a new `const_bindings` HashSet on `LoweringCtx` — the guard refuses with a clean SKIP rather than silently accepting what the interpreter rejects at runtime. Two fixtures converted; `t57_const_reassign_reject` remains a deliberate SKIP. 91 insertions, 1 deletion.
