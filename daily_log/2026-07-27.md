## Decisions and direction

**Const immutability at the semantic layer, not in backends.** The same design principle that placed width checks and the ordering-comparison allowlist in `semantic.rs` rather than in individual backends was applied here. Both backends now refuse identically before either runs. The interpreter's existing runtime guard was deliberately kept as defense-in-depth — it costs one `is_empty()` on the write path and protects against future constructs that might reach a runtime write without going through `Stmt::Assign`/`Stmt::CompoundAssign`.

**Single-choke-point over per-arm checks.** The fix was explicitly designed to avoid the pattern that caused the bug: checking each assignment form separately (the miss that let compound/index/field assignment silently mutate a const). The `assign_target_base_name` helper resolves all target forms to their root name at a single point before the target match. This mirrors the lesson from known-issues #7, where three missed width-check sites had the same class of bug.
